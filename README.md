# 通晓 · 南通大学校园政策问答

把校内规章制度、通知公告和窗口答疑记录做成一个可检索的问答站：**每句回答都带出处，查不到就明说查不到。**

纯 Python 标准库实现，无需安装任何第三方依赖（二维码功能可选装 `qrcode`），`python server.py` 直接就跑。

---

## 为什么做这个

校内政策散在教务处、学工处、后勤、保卫处等十几个站点，同一个问题常常在三四个文件里各写一句。搜索引擎按关键词给结果，学生真正想知道的是"我这种情况到底能不能办、去哪办、要带什么"。

这个项目的取舍很明确：**宁可回答"没有收录"，也不拿相近的条文凑一个看起来像答案的东西。**

## 核心设计

| 模块 | 做法 | 解决的问题 |
|---|---|---|
| 检索 | BM25 + 字符级 IDF 加权覆盖率，中文按字切分 | 不依赖分词词典，避免"业需""要条"这类切分假词误杀正确文档 |
| 排序 | 来源分级 × 时效 × 标题匹配 × 问法类型 | 政策类问法只找到新闻报道时不回答，拿新闻稿当制度依据比不答更糟 |
| 生成 | DeepSeek 归纳，强制标注 `[编号]` 来源 | 答案可回溯到原文段落 |
| 校验 | 数值/文号必须能在原文找到 | 防止模型把 30% 说成 35% |
| 限定校验 | 检测"启东校区""杏林学院""教职工专用"等排除性表述 | 答非所问的典型形态：问啬园，答启东；问本科生，答独立学院 |
| 事实层 | 人工核实的结构化条目，权重高于抓取内容 | 官网是 SPA、附件是 zip、校历是张 JPG —— 这些爬虫永远拿不到 |
| 联网兜底 | 本地无结果时抓官网页面，仅采信 `ntu.edu.cn` | 覆盖语料外的临时性问题 |
| 地图 | 42 个校内地点 + 迷你地图联动 | 回答"XX 在哪"时同时定位 |

## 快速开始

```bash
git clone <this-repo>
cd ntu

# 可选：配置大模型（不配也能跑，退化为原文摘录模式）
cp config.example.json config.json    # 填入 DeepSeek API Key

python server.py 8001
# 打开 http://127.0.0.1:8001
```

局域网访问（手机连同一个 WiFi）：

```bash
python server.py 8001 --lan
```

Windows 下双击 `start.bat`（或 `start_lan.cmd`）即可，脚本会自动探测 Python 位置。

## 数据准备

仓库**不包含**抓取的语料与地图底图，原因见下文「内容与版权」。首次运行会看到空库，按需准备：

| 脚本 | 作用 |
|---|---|
| `crawl_sites.py --pages 50` | 抓取教务处/学工处/后勤/保卫处等栏目，写入 `corpus/web_chunks.jsonl` |
| `fetch_fixed.py` | 抓固定的校情页（现任领导、作息时间、学校简介）写入事实层 |
| `add_fact.py --title --text --dept --date` | 人工录入一条已核实的事实，`--list` 可查、`--del` 可删 |
| `import_faq.py` | 批量导入结构化问答（窗口答疑表格式） |
| `tools/build_places.py` | 生成 `places.json`（42 个地点，含别名与方位描述） |
| `make_qr.py` | 按当前 IP 生成分享二维码（需 `pip install qrcode`） |

地图底图：把校园平面图放到 `web/assets/campus.webp`（建议 4096×3072，坐标系 GCJ-02）。缺图时地图页会显示空白，其余功能不受影响。

## 评测

```bash
python eval.py --llm     # 带模型，完整三层
python eval.py           # 只跑检索层，秒级
```

当前基线：

```
检索层 首条文件正确 20/20 (100%)
答案层 要素齐全    20/20 (100%)
拒答层 正确拒答     5/5  (100%)
单题平均 1.5s
```

三层分开统计，是因为它们会独立退化：只盯"答案对不对"会看不出检索跑偏，只盯检索会忽略"答错但看起来对"的情况 —— 这个项目里真实发生过两次。

## 内容与版权

- **语料**：从南通大学各官网栏目抓取，仅用于本地检索。仓库不包含正文，请勿将抓取内容二次分发。
- **地图底图**：由高德瓦片拼接，属高德地图数据，**再分发不符合其服务条款**，故未包含。请自行准备有授权的底图。
