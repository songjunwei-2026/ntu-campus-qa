# 外部验收任务：给「通晓」打分（可直接整段粘贴给 Codex）

你是外部验收方，不是开发者。任务是**证明这个站点哪里不成立**，并给出可复现的分数。
本段话优先级高于 `AGENTS.md` 里"当前任务看最新的 docs/CODEX_TASK_*.md"——那些任务一个都不要执行，本次只做评审。

## 一、边界

- 项目根 `E:\desktop\ntu`，服务已在 `http://127.0.0.1:8001` 运行（停了就 `start.bat`）。
- **只准写三个文件**：`_archive/review/codex_audit.md`、`_archive/review/codex_raw.json`、你自己的临时脚本。
- **不准改**任何 `.py` / `.html` / `.json` / `corpus/` 下的内容；**不准** `git add/commit/push/reset`。
- 结束前跑一次 `git status --short`，把造成的改动全列出来。除上面三个文件外有改动 = 越界，报告开头必须声明。

## 二、事实源

`corpus/docs_final.jsonl`（612 docs / 3180 chunks）是**唯一事实源**。判断"答案对不对"，只能拿这里的原文比，不许用你自己知道的南通大学校规去判——你不知道，语料也不知道，两边冲突时以语料为准，但要指出"语料本身可能过期"。

接口：`/api/status` `/api/keyword?q=` `/api/ask`(POST `{"q":...}`) `/api/ask/stream`(SSE) `/api/tree` `/api/places` `/api/misses`。
本机有系统代理，curl 访问 127.0.0.1 要加 `--noproxy '*'`；python 命令前设 `chcp 65001` 和 `PYTHONIOENCODING=utf-8`，否则中文输出乱码会让你误判。

## 三、必做（七组，缺一组该维度不得分）

**A 事实准确性（30 分）** —— 本次主要工作量
1. 跑 `python tools/regress.py` 和 `python tools/regress.py --ask`，记两份通过数。**不要直接采信脚本结论**，它只判标题命中。
2. 回归集 20 题**全部**逐题核，不许抽样：取 `/api/ask` 的 `answer` + 前 3 条 `citations`，用 `doc_uid`/`chunk_id` 回 `corpus/docs_final.jsonl` 取原文，逐句比对——答案里每个数字、期限、材料清单、办理地点，是否都能在引用原文找到。
3. 自拟 5 个语料明显不覆盖的问题（外地户籍入学、教师岗位工资、食堂承包商、宿舍 WiFi 密码、校领导办公电话），验证是拒答还是硬凑。
4. 找一对新旧版本文件（如同一制度 2023 版与 2026 版），问一个两者规定不同的点，看它引哪版、有没有提示以新版为准。

**B 边界与拒答（12 分）**：该拒的拒了几条、硬答几条；该答的误拒几条；拒答时给不给可操作的替代问法；研究生/教师/校外人员视角混入时是否区分适用对象。

**C 速度（15 分）**：跑 `python tools/selftest_speed.py`，记 10 题的首字节/首字/完成；自测 5 条 60 字以上长题取 p50/p90；杀进程重启测一次冷启动首请求。用 `curl -N` 看 `/api/ask/stream`，若 `meta` 里就带完整答案、或 `final` 先于 `delta`，判假流式，本项不超过 8 分。

**D 交互与可追溯（13 分）**：用内置浏览器真开 `http://127.0.0.1:8001` 提问。引用卡能否展开看原文；能否证明"这句对应文件第几段第几句"；同一页连问三轮，引用编号会不会串；断网/400/500 时用户看到人话还是 `undefined`；Tab 顺序与焦点可见性；首屏到能提问要几步。

**E 舒适度（12 分）**：量 CSS 实测值（正文 px、容器 max-width、行高），换算每行中文字数，30–45 为合格；正文/次要文字/链接三档颜色各算对比度，低于 4.5:1 列出；长答案（>400 字）能否扫读；用浏览器切 375 / 768 / 1440 三档截图，重点看移动端输入框是否被挤出视口。**没截图就说"未做视觉核验"，不许假装看过。**

**F 健壮与降级（10 分）**：0 命中时是否触发降级且界面诚实标注（还是照旧盖"已核验"章）；201 字超长、空串、纯符号、`<script>` 注入串、emoji 各发一次；并发 5 题看是否 5xx 或串答案；看 `/api/status` 的 `cache_hits`/`cache_size` 判断缓存是否真生效。

**G 可维护性（8 分）**：`server.py`（1447 行单文件）/ `llm.py`（189 行）/ `web/app.html`（776 行单文件）职责是否可切分，只给结论和最该切的 2 处；`tools/regress.py` 的判据够不够（它历史上出过"接口返回 ok 就算过"的问题）；`README.md`/`AGENTS.md` 宣称的能力与代码实际是否一致，列不一致处。
