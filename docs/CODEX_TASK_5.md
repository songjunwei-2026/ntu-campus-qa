## T12　替换首屏标题与副标题

### 现状（已核实，不用你再查）

`web/index.html` 第 185 行，整行只有一个 `<section class="hero">`：

```html
<main class="wrap"><section class="hero"><h1>每一句都有出处</h1><p>所有回答均摘自校内现行制度原文，并标注发布部门与页码</p></section>
```

两个问题：

1. **「页码」不成立**：只有 8% 的来源带页码，大部分是「部门 + 日期」。
2. **「每一句都有出处」太满**：`docs/` 里有 4 类问题目前答不上来（图书馆开放时间、医保报销、校车时刻表、2026-27 校历），
   首屏写「每一句」和实际能力不符。

### 改成（逐字照抄，不要自己润色）

```html
<main class="wrap"><section class="hero"><h1>有据可查</h1><p>每条回答都连着原文：标出发文部门和日期，点开就能核对。查不到的时候，它会直接说查不到。</p></section>
```

**逐字要求**：

- `<h1>` 内容是 `有据可查` 四个字，不要加标点、不要加英文、不要加副标题。
- `<p>` 内容是：`每条回答都连着原文：标出发文部门和日期，点开就能核对。查不到的时候，它会直接说查不到。`
  - 中间是**中文冒号** `：`，不是英文 `:`。
  - 两个句子之间是**中文句号** `。`
- `class`、`id`、标签结构一个都不许动，只换两个标签之间的文字。

### 同时调一下这行的字号（同一条需求，配套改）

第 11 行 CSS 里 `.hero p` 现在是 `font-size:13px`，新文案比原来长，13px 会挤成三行。

改法：把 `.hero p` 里的 `font-size:13px;line-height:1.9` 改成 `font-size:15px;line-height:1.85`，
并在同一规则里**追加**两个属性：`max-width:620px` 和 `text-wrap:pretty`（旧内核不支持 `text-wrap` 会自动忽略，不影响渲染）。

改完 `.hero p` 这一条规则应该是这样（其他属性保持原样，顺序不要求）：

```css
.hero p{margin:12px 0 0;color:var(--ink-3);font-size:15px;line-height:1.85;max-width:620px;text-wrap:pretty}
```
