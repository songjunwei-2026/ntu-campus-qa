## T9　地址可写：让每个答案有自己的链接

### 现状（已核实，不用你再查）

- `web/index.html` 第 763 行附近有 `?q=` 的**读取**逻辑：进页面若带 `?q=` 就自动 `ask()`。
- 但 `ask()` 答完之后**从不写地址栏**。所以答完一个问题，地址栏仍是 `/`，刷新就回空白，
  也没法把「这道题」的链接发给别人。

### 要做

1. **写地址**：`ask()` 成功渲染后更新 URL。
   - 从「空状态」提问 → 用 `history.pushState`（让浏览器「后退」能回到首页）
   - 同一问题的重复提问 → 用 `history.replaceState`（不要堆一堆历史）
   - 参数值必须 `encodeURIComponent`，中文不能截断
2. **监听后退**：`popstate` 已有监听（现在只处理视图切换）。要扩展成：地址里 `?q=` 变空 → 清空结果区并恢复示例区；`?q=` 有值且与当前答案不同 → 重新 `ask()`。
3. **复制链接按钮**：答案卡底部（反馈按钮旁边）加一个「复制链接」。
   - 复制内容：`location.origin + location.pathname + "?q=" + encodeURIComponent(question)`
   - 成功后按钮文字变「已复制」，1500ms 后恢复
   - `navigator.clipboard` 不存在时**必须降级**：把链接塞进一个只读 `<input>`，聚焦并全选，提示「请手动复制」。
     旧内核（学校老师/同学的手机浏览器）没有 clipboard API，不降级会静默失败。

### 验收（自己跑，把输出贴上来）

写一个临时脚本 `_verify_t9.py`，用 `urllib` 或直接读源码断言，跑完删除：
1. 源码里存在 `pushState` 且出现在 `ask` 函数体内（断言位置对，不是只存在）
2. 源码里存在 `encodeURIComponent`
3. 存在降级分支（`clipboard` 出现次数 ≥ 2）
4. 手工在浏览器里：提问 → 地址栏出现 `?q=%E4%BF%9D%E7%A0%94...` → 刷新仍是同一答案 → 点复制粘贴到新标签能打开

## T10　输入联想：打字时页面就开始回应

### 要做

**后端**：新增 `GET /api/suggest?q=xxx&n=6`，返回

```json
{"q": "保研", "items": [{"text": "保研需要什么条件", "kind": "faq"}, {"text": "南通大学推荐免试研究生管理办法", "kind": "title"}]}
```

- 数据源：`R.docs` 的 `title` 字段。
  - `source == "faq"` 的（共 36 条）`kind = "faq"`，**排前面**——它们本身就是同学问过的话
  - 其余约 510 个制度标题 `kind = "title"`
  - 去重（同一标题只留一次）
- **必须建一次索引、缓存住**，不许每个请求遍历 3180 条。索引放在模块级变量里，
  和 `_cache_prepare()` 一样，语料 mtime 变了才重建。
- 匹配：`q` 归一化（去空格、全半角统一、转小写）后——
  - 标题**完整包含** `q` → 基础分 100，标题越短加越多（越精确）
  - 否则按**字符覆盖率**打分（q 的字有多少出现在标题里），低于 0.5 的不返回
  - `q` 长度 < 2 → 直接返回 `{"q": q, "items": []}`，不要弹一堆
- **不许用向量、不许引依赖、不许调模型**。这是关键词匹配，几十毫秒就够。

**前端**：

- `#question` 下方出现下拉，最多 6 条，每条左边一个小标签区分 `问答` / `制度`
- 键盘：`↑` `↓` 移高亮，`Enter` 选中直接提交，`Esc` 关闭下拉（**并清掉高亮**）
- 鼠标点击也能选，选完自动提交
- 校验：输入框 blur 后 150ms 再关下拉，否则点击还没触发下拉就消失了（经典坑）
- 输入变化要防抖 120ms，不要一个字发一次请求
- 375px 宽下不许溢出屏幕，`max-height:240px` 内部滚动
- **绝对不要动 `#examplesWrap` 现有的显示/隐藏逻辑**（提问后收起、清空后恢复），那是上一批修好的

### 验收

在汇报里贴这些原始输出：

```
python -c "import server; print(server.suggest('保研', 6))"
python -c "import server; print(server.suggest('转', 6))"
python -c "import server; print(server.suggest('', 6))"
```
要求：第 1 条至少 2 项；第 2 条非空；第 3 条 `items` 为空列表。

再贴一条计时：
```
python -c "import time,server; t=time.time(); [server.suggest('奖学金',6) for _ in range(50)]; print('50 次耗时 %.3fs' % (time.time()-t))"
```
要求：50 次 < 1 秒（说明索引生效、没在每次重扫）。

## T11　骨架屏 + 分步状态：把等待变成「在干活」

### 现状

`ask()` 把 `#output` 换成一行文字「正在检索相关制度…」，1200ms 后改文案，接口回来整块替换。
两秒钟里页面只有一个字在变。

### 要做

1. **骨架屏**：提交后立刻画出答案卡的灰色骨架（不是一行字）
   - 3 条长灰条（宽度 100% / 96% / 60%）+ 1 条短条
   - 呼吸动画 1.2s 循环，纯 CSS `@keyframes`，不要第三方库
   - 灰条颜色用 `var(--line)`，不要新增颜色变量
2. **分步状态**：骨架下方三行，依次点亮（每行 600ms，**按时间推进，不要等接口**）：
   - `检索 N 段原文`（N 从 `/api/status` 的 `chunks` 取；取不到就写「正在检索原文」）
   - `核对引用位置`
   - `标注出处`
   - 已完成的行前面打 `✓` 并降到 `--ink-3`；当前行前面一个小方块做跳动动画
3. **替换**：接口回来后整块换成真实内容，过渡 ≤ 200ms，不许闪白、不许布局跳动
   （答案卡高度会变，给 `#output` 或 `.answer-block` 一个 `min-height` 兜底）
4. **失败分支**：保留「服务暂不可用」，加一个「重试」按钮，点击用上一次的问题重跑
5. `@media (prefers-reduced-motion: reduce)` 里关掉呼吸和跳动动画

### 验收

- 提交后 **100ms 内**能看到骨架（不是纯文字）
- 三行在 1.8 秒内依次点亮
- 结果替换时答案卡不发生位置跳动（头部位置稳定）
- 把 `config.json` 改名 → 提问 → 应走降级路径且**不报错**，改回来
