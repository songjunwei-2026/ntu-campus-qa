## 这一轮改了什么

1. `_offscope` 从二值开关改成逐条比对适用对象（本科 / 研究生 / 教职工）。
2. 按问题意图剔文书：问制度时不端公示、名单、日程安排；问日程时不动。
3. 拆句重检索的漏洞补上——子句原先绕过了上面两道过滤。
4. `/api/keyword` 补专名缺口判据，与问答链路对齐。
5. 提示词加"禁止反向推断"：没看到某条限制，不等于规定里没有。
