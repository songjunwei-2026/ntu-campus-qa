## 1. 上一批的教训（必读，不要重犯）

**你为了过测试加了两条无条件拦截规则，已由我改掉：**

```python
if "报到" in q: return True      # ← 已删除
if "寒假" in q: return True      # ← 已删除
```

问题：这两条不判断问的是"时间"还是"流程"，只要命中词就拒答。实测误伤
「寒假留校申请流程」「军训需要准备什么」——语料里含"留校"的文档有 48 篇、
含"军训"的有 45 篇，本来能答却被拒。

现在的写法（`server.py` 的 `_intent_mismatch`）：

```python
m_evt = re.search(r"军训|寒假|暑假|报到", q)
if m_evt and re.search(r"什么时候|什么时间|何时|几月|哪天|日期|开始|结束", q):
    if not re.search(m_evt.group(0) + r".{0,25}(\d{1,2}\s*月\s*\d{1,2}\s*日"
                                        r"|\d{1,2}\s*[:：]\s*\d{2})", corpus):
        return True
```

要点：**必须同时满足"问时间" + "语料缺完整月日/钟点"才拦**。
其中"完整月日"不能放宽成 `安排`、`日期`、`2024年12月` 这类词——都试过，全会误判
（"精细安排"是动词、文件名里的 2024年12月不是放假日期）。

**不要改回去，也不要新增任何新的无条件拒答规则。**

## 4. T4 问题级答案缓存

在 `server.py` 做**进程内**缓存，不落盘、不加依赖。

- 归一化函数单独写成 `_norm_q(q)`：去首尾空格、全角转半角、英文转小写、
  连续空白压成一个。方便单独测。
- 键 = `_norm_q(q)`
- 失效条件二选一命中即失效：跨天（按本地日期）、或语料文件 mtime 变化。
  语料版本戳从 `corpus/chunks.jsonl` 和 `corpus/facts_chunks.jsonl` 的 `os.path.getmtime` 取。
- **只缓存成功答案**：`ok=False` 的拒答、抛异常的，一律不缓存。
- 容量上限 200 条，LRU 淘汰（`collections.OrderedDict` 就够）。
- 命中计数要能读到，`/api/status` 里加 `cache_hits` / `cache_size`。

**验收**：
1. 同一问题连问两次，第二次耗时 < 100ms，答案字符串完全一致
2. `touch corpus/facts_chunks.jsonl` 后再问，缓存失效（重新走模型，耗时回到秒级）
3. 问一个会被拒答的问题两次，`cache_hits` 不应增加
